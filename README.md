# Cross-line slider recalc

A [Mapping Tools](https://github.com/OliBomby/Mapping_Tools) plugin that changes the length of the slider selected in the osu! editor so that the slider's tail ends on a grid line or on a manually entered time.

> The code in this repository was generated by **DeepSeek V4.1 Flash**.

## Build

Requires Mapping Tools 2.0.0 or newer and the .NET 10 SDK.

```
build.cmd
```

The build locates the installed Mapping Tools and compiles against that copy. When Mapping Tools is installed somewhere else, set `MappingToolsRoot` to the folder holding `Mapping_Tools.Desktop.dll`:

```
dotnet build CrossLineSliderRecalc/Mapping_Tools.CrossLineSliderRecalc.csproj -c Debug -p:MappingToolsRoot="<folder holding Mapping_Tools.Desktop.dll>"
```

The finished plugin is written to `CrossLineSliderRecalc/bin/Debug/plugin/CrossLineSliderRecalc.dll`.

## Install

Copy `CrossLineSliderRecalc.dll` into `%APPDATA%\Mapping Tools\Plugins`, then restart Mapping Tools, which scans the Plugins folder once at startup. Mapping Tools writes a plugin that fails to load to the trace rather than showing a dialog.

## Use

The beatmap has to be open in an osu! client Mapping Tools can read — osu!stable out of the box — since the tool reads the editor's selection through Mapping Tools. Select exactly one slider, set **Alignment mode**, fill in the `n` box or the **Target time** box as that mode requires, then press **Recalculate**.

With the `custom` divider, the `n` box takes beat spacings as fractions or decimals (`1/4`, `1.5`, `2`), mixed freely, and the tool uses the nearest line across all entries — a `1/12` line can be nearer than a `1/4` line. **Custom end time** reads the **Target time** box as milliseconds (`16571`) or as an editor timestamp (`00:16:571`), ignoring whatever follows the first space, so a timestamp copied from the editor, like `00:16:571 - `, can be directly pasted.

Grid lines are bounded by the redlines: a line from one redline's section never lands past the redline that ends that section, and each redline is itself the first line of its own section. A slider's duration is computed from the redline at its head even when the slider crosses a later redline.

The tool page writes the beatmap but leaves the editor showing the slider's old length, so press Ctrl+L in osu! to reload the map. A run from QuickRun, offered when exactly one object is selected, reloads the map automatically when the **Editor reload** preference in Mapping Tools is enabled.
